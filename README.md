# 🌐 FlowMind · Liquidity OS (Technical Architecture)

**FlowMind** — это высокотехнологичная платформа для мониторинга финансовой ликвидности и инфраструктуры платежных систем. Проект эволюционирует от высокоэффективного SPA-прототипа до полноценной корпоративной системы обработки реальных данных.

---

## 🏗 Текущая архитектура (v1.0 - SPA)
На данный момент система представляет собой модульный фронтенд, обеспечивающий бесшовный пользовательский опыт:

* **Инфраструктурная панель:** Динамический мониторинг TPS, анализ объема платежей (24ч/7д/30д) через SVG-визуализацию.
* **Pulse Feed:** Живая лента транзакций (SEPA, SWIFT, CARD) с имитацией нагрузки.
* **Smart Onboarding:** Форма регистрации с динамической подгрузкой платежных систем в зависимости от выбранного региона (Европа, Азия, Америка, Ближний Восток).
* **State Management:** Безопасное хранение сессий через `localStorage` и модульная архитектура на чистом JS.

---

## 🛠 План миграции: Переход на Full-Stack
С переходом на серверную обработку данных архитектура будет модернизирована:

1. **Безопасность:** Отказ от `localStorage` в пользу `JWT-токенов` с реализацией ролевой модели доступа (RBAC).
2. **Real-time Data:** Замена клиентской генерации случайных чисел на протокол **WebSockets** для трансляции данных о транзакциях в реальном времени.
3. **Infrastructure:** Перенос бизнес-логики на серверную часть и использование реляционной БД для хранения истории транзакций и состояния счетов.
4. **Stress Testing:** Функциональная реализация стресс-тестов через фоновые воркеры (Background Workers) для имитации скачков нагрузки в 300%.

---

## 🗺 Roadmap: Развитие UI/UX
В рамках превращения FlowMind в коммерческий продукт запланировано:

* **Расширение вкладок:** Реализация полноценных модулей «Счета» и «Транзакции» (генерация IBAN, управление лимитами).
* **Data Visualization:** Миграция с SVG-полилиний на профессиональные библиотеки (**ApexCharts** / **Chart.js**) с поддержкой интерактивного масштабирования и Tooltips.
* **Advanced Search & Filtering:** Полнотекстовый поиск по ID транзакций с пагинацией и гибкими фильтрами.
* **Incident Management:** Внедрение системы **Toast-уведомлений** и кликабельных алертов с прямым переходом к техническим логам ошибок.
